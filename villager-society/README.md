# Общество жителей (Villager Society) — Fabric, Minecraft 1.21.11

Мод про жителей в твоей подземной коробке. Работает на сервере/в одиночке, клиенту ничего ставить не нужно (кроме Fabric API).

## Как это работает
- **Сначала иерархии нет.** Жители равны, имена над головами без званий.
- **Собрания.** Жители рядом периодически собираются, разговаривают в чате и голосуют: «кто главнее» и «кто хуже». У каждого жителя СВОЁ мнение о каждом (хранится в мире), и после голосов он сам решает, соглашаться с большинством или нет.
- **Ранги** считаются из мнений всех: `Правитель`, `Знать`, `Простолюдин`, `Изгой`. Меняются при следующих голосованиях — кто-то растёт, кто-то падает.
- **Еда по рангам.** Раз в ~25 сек. вся еда общины (хлеб, морковь, картошка, свёкла) собирается и делится: сначала малыши (до 4 шт.), потом по рангу — правитель 16, знать 8, простолюдин 3, изгой 1. Остатки забирают верхние. Нет еды — слабые ходят медленно и жалуются.
- **Сон.** Изгои не спят и не отдыхают — всю ночь стоят. Простолюдины стоят по очереди (через ночь). Правитель и знать спят.
- **Командование.** Правитель посылает слабых с данью (еда → ему лично), если принесли пустые руки — толкает. Знать и правитель расталкивают нижних.
- **Малыши под защитой:** без ранга, их не толкают, не гоняют, кормят первыми.
- **Разговоры.** Жители общаются в чате (слышно в радиусе 40 блоков): болтовня зависит от ранга, малыши тоже говорят.
- Команда `/society` — список жителей рядом с рангом, очками и едой.

## Сборка через GitHub (без установки чего-либо на компьютер)
1. Создай на github.com новый репозиторий (New repository).
2. Нажми «uploading an existing file» и перетащи ВСЁ содержимое распакованной папки `villager-society` (включая скрытую папку `.github`, она важна). Нажми Commit.
3. Открой вкладку **Actions** — сборка запустится сама (или Run workflow вручную). Займёт 3–5 минут.
4. Когда появится зелёная галочка, открой запуск → внизу **Artifacts** → скачай `villager-society-jar`. Внутри jar без `-sources` положи в `mods/` вместе с Fabric API.
5. Если сборка красная — открой её лог, скопируй ошибку и пришли мне, исправлю.

## Сборка локально
1. Лучше всего: скачай официальный шаблон на https://fabricmc.net/develop (Minecraft 1.21.11, Yarn), и скопируй в него папку `src/` из этого архива (замени fabric.mod.json).
2. Либо используй build.gradle из архива — но версии в `gradle.properties` проверь на fabricmc.net/develop.
3. Нужна Java 21. Команда: `./gradlew build` → jar в `build/libs/` (не `-sources`).
4. Положи jar в `mods/` вместе с Fabric API.
